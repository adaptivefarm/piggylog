# Examples — all invented

**Nothing in this folder is real.** It is a made-up farm, with made-up pigs and
made-up prices, so you can see what a filled-in record looks like before you have one.

**Delete this whole folder when you start your own records.** Leaving it in place
risks an agent reading these numbers as if they were yours.

```bash
rm -rf examples/
```

The invented farm: six pigs bought on 2026-01-10 — four male for meat, two female
kept for breeding. Feed prices are round numbers chosen to be obviously fake.

| File | Shows |
|---|---|
| `example-daily-log.md` | An ordinary day, with a weigh-in |
| `example-feed-costs.md` | What the feed ledger looks like with rows in it |
| `example-intervention.md` | One health entry, with the cross-link |
