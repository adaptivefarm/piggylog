👋 Start here

This farm record is empty. Nothing below is real — the numbers are placeholders showing where things go.

Open this folder with a coding assistant that can read and write files — Claude Code, Codex or Cursor — and say: “Help me set up records for my pig farm.” It will ask about your pigs, your feed and your costs, then fill this page in.

A phone chat app cannot do this. It can answer questions, but it cannot save today's log and still have it tomorrow. See README.md.

Agents: work through the setup questions in CLAUDE.md with the farmer before writing anything here. Replace every SETUP NEEDED, then delete this section.

How feed is portioned

Some farms pre-portion feed into numbered containers — that turns feeding into a count instead of a guess, and makes intake history accurate for free. Others scoop straight from the sack. Record what this farm actually does. If containers are used, write down how many exist and the fill weight, and note the date whenever the fill weight changes. See RECORDKEEPING.md.

▸ Money — does this batch pay? SETUP NEEDED

The point of this section is one number: the price per kilo at which this batch breaks even. Below it the farm loses money on every pig. Most farms have never calculated it, and it is usually the most useful thing in the whole repo.
